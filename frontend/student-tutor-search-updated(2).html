Graph Traversal — BFS & DFS Applications
24:45
Question 1 of 10 (Single Choice • +4 / -1 Mark) Data Structures • Practice Drill
Algorithmic Complexity Question:
What is the time complexity of Breadth-First Search (BFS) on a graph with V vertices and E edges when represented using an adjacency list?
Core interview question tested in technical screening and campus placements.
Correct! Option (A) O(V + E) is the right answer (+4 Marks).

Faculty Solution: With an adjacency list representation, BFS visits each vertex once (O(V)) and inspects each edge once (O(E)), giving total time complexity O(V + E).

Lecture Slide Deck
Lec 12: Graph Traversal Algorithms (BFS & DFS)
Data Structures • Prof. Rohit Verma Slide 4 of 32
Breadth-First Search: Queue-Based Traversal
Queue<Integer> queue = new ArrayDeque<>();
queue.add(startNode); visited[startNode] = true;
Key Traversal Insight: BFS discovers nodes level-by-level using a First-In-First-Out (FIFO) queue. It guarantees the shortest path on unweighted graphs.
Space & Time Complexity: Time: O(V + E) with adjacency list.
Space: O(V) for the boolean visited array and BFS queue memory.
